## محتويات المشروع
1. **`index.html`**: ملف الصفحة الرئيسي متضمناً كامل الهيكل المطلوب والعناصر البرمجية وفق المعايير المحددة (عناوين، فقرات، نصوص عريضة، صور، جداول مقارنة، قوائم مراجع، وروابط تشعبية).
2. **`cloud_architecture.png`**: الصورة التوضيحية المربوطة بالصفحة والتي تعبر عن معمارية السحابة وتطبيقات الإنترنت.
3. **`README.md`**: توثيق المشروع وبياناته.

---

## المتطلبات البرمجية المحققة
- [x] الهيكل الأساسي للصفحة (`<html>`, `<head>`, `<body>`, `<title>`).
- [x] ترويسة الصفحة بعنوان رئيسي `<h1>` وتحته بيانات الطالب داخل وسوم `<p>`.
- [x] عناوين فرعية منقسمة بـ `<h2>` و `<h3>` (المقدمة، عرض الموضوع، المراجع).
- [x] تنسيق النصوص باستخدام `<strong>` و `<b>` والفقرات `<p>`.
- [x] إضافة صورة معبرة باستخدام `<img>` مع تحديد خاصيتي `src` و `alt`.
- [x] جدول مقارنة تحليلي منظم باستخدام `<table>`, `<tr>`, `<th>`, `<td>`.
- [x] قائمة غير مرتبة للمراجع باستخدام `<ul>` و `<li>`.
- [x] روابط تشعبية قابلة للنقر لجميع المراجع باستخدام `<a>` وخاصية `href`.
